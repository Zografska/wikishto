# P0.1 — Monorepo scaffold
Model: haiku · Depends: none · autogo

**Goal:** an empty monorepo where every package installs, typechecks and runs an empty test suite.

**Read:** CLAUDE.md only.

**Touch:** `package.json`, `pnpm-workspace.yaml`, `.gitignore`, `biome.json`, `shared/{package.json,tsconfig.json,index.ts}`,
`worker/{package.json,tsconfig.json,wrangler.toml,src/index.ts,vitest.config.ts}`, `web/` (Vite React TS + Tailwind + shadcn init),
`pipeline/{pyproject.toml,wikishto/__init__.py,wikishto/cli.py,tests/test_smoke.py}`.

**Contract:**
- pnpm workspace: `shared`, `worker`, `web`. Every TS package has scripts `test` (vitest), `typecheck` (tsc --noEmit), `lint` (biome).
- `worker`: Hono app with `GET /health` returning `{ok:true}`; `wrangler.toml` with name `wikishto`, no IDs yet (placeholders).
- `web`: `HashRouter`, Vite `base: '/wikishto/'`, one route `/` rendering "WikiShto".
- `pipeline`: `uv`, Python 3.11+, deps typer; dev deps pytest, ruff. `wikishto` console script → Typer app with a `version` command.
- `.gitignore`: `node_modules/`, `dist/`, `.wrangler/`, `pipeline/data/`, `pipeline/out/`, `.venv/`, `__pycache__/`.

**Acceptance:** each package has one passing smoke test.

**Done-check:** `pnpm install && pnpm -r typecheck && pnpm -r test -- --reporter=dot && (cd pipeline && uv run pytest -q)`

**Out of scope:** game logic, CI workflows, real Cloudflare IDs.
