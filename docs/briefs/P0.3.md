# P0.3 — Normalizers (TS + Python)
Model: sonnet · Depends: P0.2

**Goal:** one normalization, two implementations that can't drift.

**Read:** `shared/normalize-cases.json`, `shared/api-types.ts`.

**Touch:** `shared/normalize.ts`, `shared/normalize.test.ts`, `pipeline/wikishto/normalize.py`, `pipeline/tests/test_normalize.py`.

**Contract:**
- Normalize: trim, lowercase, ѐ → е, ѝ → и.
- Classify input: `word` = Cyrillic letters only; `number` = digits with at most one `,` or `.` between digits (`2,1` == `2.1`); anything else `invalid`. Hyphens are never valid input.
- Return `{kind, value}`; numbers also carry the numeric value.

**Acceptance:** both suites loop over every case in `normalize-cases.json` and match its expected output exactly.
If the fixture has fewer than 10 cases, stop: the owner writes it first.

**Done-check:** `pnpm -C shared test -- --reporter=dot && (cd pipeline && uv run pytest -q -x tests/test_normalize.py)`
