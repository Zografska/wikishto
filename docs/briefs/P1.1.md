# P1.1 — Pipeline spike on 10 articles
Model: sonnet · Depends: P0.3

**Goal:** real blobs for 10 articles plus size numbers, quick and dirty.

**Read:** `shared/puzzle.ts`, `shared/puzzle-format.md`, `pipeline/wikishto/normalize.py`.

**Touch:** `pipeline/spike/*.py`, `pipeline/spike/README.md`, `pipeline/tests/test_spike_clean.py`, `pipeline/pyproject.toml` (may add mwparserfromhell, classla, numpy).

**Inputs (owner provides):** `pipeline/data/mkwiki-latest-pages-articles.xml.bz2`, `pipeline/data/cc.mk.300.vec.gz`, `pipeline/spike/ids.txt` (10 titles).

**Contract:**
- Stream the dump; stop once all 10 titles are found. Namespace 0, skip redirects.
- Clean the intro: templates, refs, files, IPA, parenthetical foreign-language glosses. Strip title disambiguators ("Охрид (град)" → "Охрид").
- Tokenize: word / number (`2,1` is one token) / punct / latin; hyphenated compounds are two word tokens. Cut at a sentence boundary at 200–350 words.
- CLASSLA `mk` in context, pretokenized, to get lemmas. Normalize everything with `normalize.py`.
- Vocab: first 100k Cyrillic forms of the `.vec` (it is frequency-ordered); lemmatize out of context in batches; cache to `pipeline/out/spike/vocab.tsv`.
- Lemma vector = vector of the lemma's own form if present, else mean of its forms. Cosine vocab-lemmas × article-lemmas with numpy; keep ≥ 0.30.
- Write one blob per article to `pipeline/out/spike/<slug>.json`, and `sizes.csv`: slug, raw bytes, gzip bytes, pairs, at 0.30 and at 0.35.

**Acceptance:** tests for clean / tokenize / cut on 3 inline wikitext snippets.

**Done-check:** `cd pipeline && uv run pytest -q -x && uv run python -m spike.run && wc -l out/spike/sizes.csv`

**Out of scope:** CLI polish, scheduling, upload. Print counts only, never file contents.
