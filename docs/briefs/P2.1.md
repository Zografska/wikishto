# P2.1 — `candidates` command
Model: sonnet · Depends: P1.3

**Goal:** turn the dump + pageviews into a review CSV of puzzle candidates.

**Read:** `pipeline/spike/clean.py`, `pipeline/spike/tokenize.py` (or the spike files that hold that logic), `pipeline/wikishto/normalize.py`, `pipeline/wikishto/cli.py`.

**Touch:** `pipeline/wikishto/{cli,pageviews,candidates,clean,tokenize}.py`, `pipeline/tests/test_clean.py`, `pipeline/tests/test_candidates.py`.

**Contract:**
- Move spike cleaning and tokenizing into `wikishto/` with tests; delete nothing from `spike/`.
- Pageviews: Wikimedia REST "top articles" per month for `mk.wikipedia`, all-access, last 12 full months; sum views per title. Cache raw JSON in `pipeline/data/pageviews/`.
- Pool: top ~3,000 by views. Drop disambiguation pages, lists, date and year articles, and anything under 120 words after cleanup.
  Detect disambiguation by its template/category; if unsure of the Macedonian template name, print the 5 most common candidates and ask the owner.
- Output `pipeline/out/candidates.csv`: id, title, url, views, words, preview (first 30 words), approved (empty).

**Acceptance:** cleaning cases (templates, refs, files, IPA, foreign glosses, disambiguator, sentence cut 200–350, under-120 drop); filter cases for list/date/year titles.

**Done-check:** `cd pipeline && uv run pytest -q -x && uv run wikishto candidates --limit 50`

**Out of scope:** lemmatization, similarity.
