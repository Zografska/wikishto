# P2.2 — `vocab` command
Model: sonnet · Depends: P2.1

**Goal:** the vocabulary table and lemma vectors every puzzle build uses.

**Read:** spike vocab code, `pipeline/wikishto/normalize.py`, `pipeline/spike/RESULTS.md` (Decision section).

**Touch:** `pipeline/wikishto/{cli,vocab}.py`, `pipeline/tests/test_vocab.py`.

**Contract:**
- Top 100k Cyrillic forms from `cc.mk.300.vec.gz`, normalized, deduplicated. Lemma per form via CLASSLA (most frequent lemma when ambiguous).
- Write `out/vocab.tsv` (form, lemma), `out/lemmas.txt` + `out/vectors.npy` (one unit-normalized vector per lemma).
- Write the D1 load as `out/vocab.part1.sql` and `out/vocab.part2.sql`, each 60k rows or fewer, batched INSERTs of 500 (D1 Free allows 100k row writes a day).
- Skip work whose output already exists unless `--force`.

**Acceptance:** with a 10-line fake `.vec` and a stub lemmatizer: dedup, normalization, Latin forms dropped, SQL split and escaping correct.

**Done-check:** `cd pipeline && uv run pytest -q -x tests/test_vocab.py`
