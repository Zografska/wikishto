# P2.3 — `build` command + validation
Model: sonnet · Depends: P2.2

**Goal:** approved articles → validated puzzle blobs.

**Read:** `shared/puzzle.ts`, `shared/puzzle-format.md`, `pipeline/wikishto/{clean,tokenize,vocab}.py`, spike similarity code.

**Touch:** `pipeline/wikishto/{cli,build,similarity,validate}.py`, `pipeline/tests/test_build.py`, `pipeline/tests/test_validate.py`.

**Contract:**
- Rows with `approved` = y in `candidates.csv` only. CLASSLA in context (pretokenized). Blob exactly per `shared/puzzle.ts` at the current `v`.
- Similarity floor from config (default per RESULTS.md). Pairs expanded to slots.
- Validation (any failure skips that article and reports why): every word slot's form is in the vocab or the article; every title word has a slot and a lemma;
  blob under the size cap from RESULTS.md; schema matches `v`.
- Write `out/puzzles/<id>.json` and print a summary table (id, title, words, pairs, bytes, ok/why).

**Acceptance:** fixture article builds; three broken fixtures fail validation with the right reason.

**Done-check:** `cd pipeline && uv run pytest -q -x tests/test_build.py tests/test_validate.py`
