# P3.1 — Worker pure modules
Model: sonnet · Depends: P1.3

**Goal:** all matching rules as pure, unit-tested functions.

**Read:** `shared/api-types.ts`, `shared/puzzle.ts`, `shared/normalize.ts`, `shared/function-words.mk.json`, `shared/fixtures/puzzle.sample.json`.

**Touch:** `worker/src/{config,today,numbers,guess,solve,skeleton}.ts` + `worker/test/*.test.ts`.

**Contract:**
- Today = Europe/Skopje date at request time (`Intl.DateTimeFormat`). Puzzle number = days since `LAUNCH_DATE` + 1. Dates after today are rejected.
- Numbers skip the vocab. Exact = same value. Near = ±10 for year-like (4 digits, 1000–2100), else ±10%. Values from config.
- Words: accepted if `lemmaOf(form)` finds it or the form appears in today's article; else `unknown` (not counted). `lemmaOf` is injected.
- Hits = `lemmaSlots[lemma]` → `{slot, text}`. Near = `near[lemma]` filtered: 0.40 content↔content, 0.60 if either side is a function word; tagged `content|function`.
- Solve: replay all guesses; 200 only if every title slot is hit, else 403.
- Skeleton: from a puzzle blob, emit only what `api-types.ts` allows — never lemmas or hidden text.

**Acceptance:** куќа reveals куќата and куќи; ѐ/ѝ fold; `2,1` equals `2.1`; 1945 near 1950, not 1961; 100 near 108; unknown word not counted;
function-word pair at 0.55 dropped, content pair at 0.45 kept; future date rejected; solve missing one title word → 403; skeleton has no lemma or hidden text.

**Done-check:** `pnpm -C worker test -- --reporter=dot && pnpm -C worker typecheck`
