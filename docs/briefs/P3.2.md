# P3.2 — Storage, logging, migrations
Model: sonnet · Depends: P3.1

**Goal:** KV and D1 access behind small interfaces.

**Read:** `shared/puzzle.ts`, `worker/src/config.ts`, `worker/wrangler.toml`.

**Touch:** `worker/src/{store,log}.ts`, `worker/migrations/0001_init.sql`, `worker/test/store.test.ts`, `worker/test/log.test.ts`, `worker/vitest.config.ts`.

**Contract:**
- `getPuzzle(date)`: KV `puzzle:mk:<date>`, parsed and cached in a module-level Map (3 entries max).
- `lemmaOf(form)`: D1 `SELECT lemma FROM vocab WHERE form = ?`, small LRU (500).
- D1 tables: `guesses` (puzzle_date, player_id, guess_no, guess, result hit|near|miss|unknown|invalid, hit_count, best_sim, ts),
  `solves` (puzzle_date, player_id, total_guesses, pct_revealed, as_today, ts), `vocab` (form PK, lemma). Index on puzzle_date.
- Logging runs in `ctx.waitUntil`. Never IP, user agent or location.

**Acceptance:** with `@cloudflare/vitest-pool-workers`: cache hit avoids a second KV read; missing date → null; lemma lookup; inserts land with the right columns.

**Done-check:** `pnpm -C worker test -- --reporter=dot`
