# P3.3 — Routes, CORS, rate limit, health
Model: sonnet · Depends: P3.2

**Goal:** the five endpoints wired end to end.

**Read:** `shared/api-types.ts`, `worker/src/*.ts` (exports only), `worker/wrangler.toml`.

**Touch:** `worker/src/index.ts`, `worker/wrangler.toml`, `worker/test/integration.test.ts`.

**Contract:**
- Routes exactly per `api-types.ts`. CORS allows only `env.ALLOWED_ORIGIN`.
- Rate limit: the Workers rate-limiting binding, 30 guesses/min per IP; IP used only as the key, never stored. Over → 429 `{error:'rate_limited'}`.
  The binding syntax has changed across wrangler versions: follow the installed wrangler's types (`wrangler types`).
- Vars: `THRESH_CONTENT=0.40`, `THRESH_FUNCTION=0.60`, `YEAR_MIN=1000`, `YEAR_MAX=2100`, `YEAR_DELTA=10`, `NUM_PCT=0.10`, `LAUNCH_DATE`, `ALLOWED_ORIGIN`.
- Cache-Control: past puzzles immutable; today's until Skopje midnight; `/guess` and `/solve` no-store.
- `/health`: count of consecutive dates from today present in KV (stop at the first miss, 60 gets max).

**Acceptance:** skeleton JSON contains no lemma and no hidden word; future date 404; guess flow; unknown word; solve 403 then 200; CORS header; 429 path; health count.

**Done-check:** `pnpm -C worker test -- --reporter=dot && pnpm -C worker typecheck`
