# P4.1 — App shell, API client, storage, game reducer
Model: sonnet · Depends: P3.3

**Goal:** all game state as a pure reducer, with the plumbing around it.

**Read:** `shared/api-types.ts`, `web/src/main.tsx`, `web/src/App.tsx`.

**Touch:** `web/src/{App.tsx,strings.mk.ts}`, `web/src/lib/{api,storage,player}.ts`, `web/src/game/{types,reducer,stats}.ts` + tests.

**Contract:**
- Routes (HashRouter): `/` today, `/archive`, `/:date`, `/about`. API base URL from `VITE_API_URL`.
- `api.ts`: the four calls typed from `shared/api-types.ts`; one `ApiError` for 404, 403, 429 and network failure.
- `storage.ts`: keys `wikishto:v1:<date>`, `wikishto:v1:player`, `wikishto:v1:stats`, `wikishto:v1:settings`. Every read and write in try/catch with an in-memory fallback.
- Per date, store the guess list with each server result. State is rebuilt by replaying it (no refetch).
- Reducer: revealed slot → text; best near miss per slot `{guess, sim, kind}`, replaced only by a higher sim; score = accepted guesses;
  % revealed = revealed word blocks (word + number, title included) ÷ all of them; solved = all title slots revealed.
- `strings.mk.ts`: typed keys; include "Непознат збор" and "Полека, размисли малку 😛"; everything else `TODO_MK`.

**Acceptance:** replay equals step-by-step; a closer near miss replaces a weaker one, never the reverse; unknown/invalid don't count; % revealed math; storage throws → app still works.

**Done-check:** `pnpm -C web test -- --reporter=dot && pnpm -C web typecheck`
