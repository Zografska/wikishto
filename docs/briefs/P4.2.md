# P4.2 — ArticleView and GuessInput
Model: sonnet · Depends: P4.1

**Goal:** the core screen: hidden article, blocks, input.

**Read:** `web/src/game/types.ts`, `web/src/game/reducer.ts` (exports only), `web/src/strings.mk.ts`, `shared/api-types.ts`.

**Touch:** `web/src/components/{ArticleView,Block,GuessInput}.tsx`, `web/src/pages/Today.tsx`, `web/src/pages/Puzzle.tsx`, `web/src/styles/game.css` + tests.

**Contract:**
- Title on top, article below. Hidden block = grey box sized by letter count. Tap/click a block → shows its count until revealed.
- Revealed = plain text with a brief flash. Near miss = the guess word in the slot, styled by CSS variables `--near-content-<0..4>` (by sim) or `--near-function` + italics.
- Punctuation, Latin tokens and number separators are shown from the start.
- Input pinned to the bottom on mobile; same character check as the server (shared normalizer); hint line for unknown/invalid/429 from strings.
- Screen readers: hidden block labelled with its letter count; focus returns to the input after each guess.

**Acceptance (Testing Library):** tap shows count; hit reveals all slots of the lemma; near miss italic for function; invalid input blocked before the request; 429 shows the rate-limit string.

**Done-check:** `pnpm -C web test -- --reporter=dot && pnpm -C web typecheck`
