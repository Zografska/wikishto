# P4.3 — GuessList, WinScreen, share, streak
Model: sonnet · Depends: P4.2

**Goal:** the loop around a guess: history, winning, sharing.

**Read:** `web/src/game/{types,stats}.ts`, `web/src/lib/api.ts` (exports only), `web/src/strings.mk.ts`.

**Touch:** `web/src/components/{GuessList,WinScreen,ShareButton}.tsx`, `web/src/game/{share,streak}.ts` + tests.

**Contract:**
- GuessList: shadcn Sheet on mobile, side panel on desktop; newest first; each row "guess — exact-hit count".
- WinScreen: calls `/solve`; shows full article, Wikipedia link, score, % revealed, streak, share button.
- Share text: `WikiShto #N — решено во X обиди, Y% откриено` + game link, + streak when above 1. No spoilers.
- Streak = consecutive days on which that day's puzzle was solved as today's puzzle (server date). Archive solves get a checkmark only.

**Acceptance:** share text exact (with and without streak); streak continues, breaks on a missed day, ignores archive solves; solve 403 keeps the game open.

**Done-check:** `pnpm -C web test -- --reporter=dot && pnpm -C web typecheck`
