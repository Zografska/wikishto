# P5.1 — GitHub Actions workflows
Model: haiku · Depends: P4.5 · autogo

**Goal:** the three workflows from the plan.

**Read:** root `package.json`, `web/vite.config.ts`, `worker/wrangler.toml`.

**Touch:** `.github/workflows/{deploy-web,deploy-worker,schedule-check}.yml`.

**Contract:**
- `deploy-web`: push to `main` touching `web/**` or `shared/**` → pnpm install → test → build (base `/wikishto/`, `VITE_API_URL` from repo variable) → Pages deploy.
- `deploy-worker`: push to `main` touching `worker/**` or `shared/**` → install → test → `wrangler d1 migrations apply wikishto --remote` → `wrangler deploy`. Secrets `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`.
- `schedule-check`: weekly cron + `workflow_dispatch` → `curl $API/health` → if fewer than 14 days and no open issue labelled `schedule`, `gh issue create --label schedule`.
- Pin action versions; `concurrency` per workflow.

**Acceptance:** `actionlint` passes (run via `pnpm dlx` or docker if available, else skip and say so).

**Done-check:** `ls .github/workflows`
