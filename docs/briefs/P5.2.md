# P5.2 — Soft-launch queries
Model: haiku · Depends: P3.2

**Goal:** the four saved D1 queries for weekly review.

**Read:** `worker/migrations/0001_init.sql`.

**Touch:** `ops/queries.sql`, `ops/README.md`.

**Contract (one commented query each):**
1. Solve rate and median guesses per puzzle date.
2. Near-miss usefulness: guesses whose near misses lit many slots and were followed by no guess sharing a hit within the next 3 guesses.
3. Unknown-word rate per date and the top 50 rejected guesses.
4. Drop-off: players with guesses but no solve, grouped by their last guess number.
README: how to run each with `wrangler d1 execute wikishto --remote --command` (owner runs it).

**Acceptance:** all four run against local D1 seeded with a few rows.

**Done-check:** `pnpm -C worker exec wrangler d1 execute wikishto --local --file ../ops/queries.sql`
